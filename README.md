# ✦ Change Of Scene — лиминальное кафе

**Change Of Scene** — это веб-сайт-атмосфера, посвящённый вымышленному кафе, расположенному в *контролируемом лиминальном пространстве*. Проект сочетает эстетику сюрреализма, музыку и кулинарную фантазию, предлагая посетителю меню несуществующих вкусов, архив тайн и свидетельства гостей.

Сайт полностью статический, адаптивный, с поддержкой двух языков (русский/английский) и фоновой анимацией на Three.js.

## 🚀 Запуск локально

Сайт статический — достаточно открыть `index.html` в браузере.

Для удобства можно использовать любой HTTP-сервер, например:

```bash
# Python 3
python3 -m http.server 8123

# Или с Node.js
npx serve .
```

После запуска откройте `http://localhost:8123` в браузере.

## 🛠 Технологии

- **HTML5**, **CSS3** (адаптивная вёрстка, тёмная тема, кастомные шрифты)
- **JavaScript** (чистый ES6, без фреймворков)
- **Three.js** (фоновая анимация)
- **Font Awesome** (иконки)
- **Мультиязычность** (переключение через localStorage, автоопределение языка браузера)

---

## 🌍 Поддержка языков

- Русский (по умолчанию для русскоязычных браузеров)
- Английский

Переключение — по кнопке 🌐 в правом верхнем углу. Выбранный язык сохраняется в `localStorage`.

## ✨ Особенности

- Лиминальная эстетика: мягкое освещение, мрамор, карты несуществующих городов
- Динамическое меню с разделами: горячие напитки, холодные коктейли, десерты, закуски, первые и вторые блюда
- Архив с анимированным раскрытием записей по годам
- Свидетельства гостей с рейтингами (10-балльная шкала)
- Интерактивный фон, меняющийся в зависимости от времени суток (реализовано в `neural-bg.js`)
- Адаптивная вёрстка для мобильных устройств

## 🧑‍💻 Разработка

Если вы хотите внести изменения:

1. Клонируйте репозиторий
2. Внесите правки в соответствующие файлы (контент — в `content/*.js`, стили — в `style.css`, логика — в `page.js`)
3. Проверьте работу локально
4. Отправьте Pull Request

При добавлении новых пунктов меню или архивных записей следуйте структуре данных в `content/*.js`.
